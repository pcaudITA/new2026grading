# G2026 Transition — public explainer site

Static site (GitHub Pages): what changed from the 2023 codes to PCaudit G2026.
- index.html (EN) · it.html · es.html · transition-assets/ (infographics + video slot)
- To publish updates: edit files, then double-click "Publish Transition Site.command".
- The video: drop transition-assets/transition.mp4 (or set a YouTube ID in each html's data-yt) and publish.
Canonical URL: https://g2026.pcaudit.eu/
